IVANS (Ivans Insurance Solutions) connects insurance carriers, MGAs and agencies with data exchange, download, distribution and market-access products. Its developer portal at api.ivans.com publishes REST API references for the Ivans Distribution Platform (FastIDP), Identification Network, IVANS Exchange (v1-v3), Translation, Download, Insights and Passport, with OAuth token-based authentication.

**Areas:** Company · Insurance · Data Exchange · Insurance Distribution · Agencies · Carrier

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for IVANS: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
